# 项目类型适配

先读实际技术栈和命令，不要求所有平台安装同一套工具。

| 类型 | 重点 | 验证方式 |
| --- | --- | --- |
| Web 管理端 | 操作、表单、分页/筛选、导出、四层权限、主从单据 | 实际构建/类型检查，现有浏览器回归，接口与数据结果 |
| 展示站/门户 | 路由、内容来源、资源、表单、响应式与可访问性 | 页面渲染、键盘交互、真实表单结果；无后台的页面不补造 RBAC |
| 微信小程序/跨端 | 登录态、权限、请求域名、生命周期、上传、真机行为 | 已有开发者工具/真机，目标平台编译；不以 H5 替代 |
| WinForms/WPF | 绑定、校验、窗体生命周期、UI 线程与部署依赖 | 项目现有编译/运行工具，逐窗体关键流程 |
| Java Swing | EDT、模型刷新、线程、文件编码和打包 | 实际 JDK/构建命令，窗体与数据行为 |
| API/Worker | 输入、授权上下文、重试/幂等、事务、队列结束态 | 定向契约与集成测试；没有 UI 时不编造按钮点检结果 |

图表共用业务证据原则；架构中客户端与通信方式按平台真实实现变化，不把所有项目都套成 Vue+Spring。
