# 按事实选用的加固检查表

每项记录 `适用/不适用`、证据与验证状态；没有需求依据的建议留在建议区，不自动实施。

## 基线与范围

- [ ] 识别真实项目、技术栈/版本、环境、用户与核心业务；保护已有改动。
- [ ] 建立页面/窗体、入口、操作、接口、权限、数据模型映射，空壳与已实现分开。
- [ ] 明确测试账号/数据与运行命令，确认不连接生产；无法判断时先不做写操作。
- [ ] 记录问题复现、当前测试失败和完成定义，避免把既有问题记作本轮引入。

## 主从单据与业务边界

- [ ] 确认疑似行项目是否依附主单，是否有独立生命周期及高频业务；证据不足保留现状。
- [ ] 需要归并时连同保存事务、明细归属校验、状态锁定、金额重算、查询、权限与导出收口。
- [ ] 保留合法审计/跨单查询；菜单合并不代表物理表合并或历史明细必须删除。

## 逐菜单逐页面业务改造与复验

- [ ] 按 [逐页业务协议](page-business-redesign.md) 双重枚举真实菜单/路由/角色和界面，覆盖列表、创建、编辑、详情、弹窗与无菜单入口。
- [ ] 每页写明用户目标、上下文/生命周期、主要动作与完成结果，明确保留并优化列表/重做业务工作页/完善已有业务页的依据。
- [ ] 特殊业务操作贯通真实接口/服务/权限/状态/事务和反馈，不能只改样式或把“办理”跳到普通编辑表单；合理列表不强改卡片。
- [ ] 全部相关实现和测试编写完成后，集中逐页业务形态复审与真实操作验收；截图、操作预期/实际、真实尺寸和角色/适用状态均有证据。
- [ ] 失败按问题ID/轮次/版本返工，复验该页与共享受影响页并关闭旧问题；最终重新枚举全量核对，不漏页、不复用失效证据。
- [ ] 交付 [审查JSON记录](page-redesign-audit-format.md) 并运行清单检查器；结果仅说明结构/指纹/证据完整性，未验证页保留真实状态，不删页凑通过。

## 表单、列表与筛选

- [ ] 关联选项加载/远程搜索、可见名称和提交 ID 一致；编辑回填正确。
- [ ] 必填、唯一、数值、日期、关联及状态校验由后端落实；失败时保留输入并恢复交互。
- [ ] 操作能力与 UI 入口、接口和授权一致；每种操作验证实际业务结果。
- [ ] 每个相关筛选检查前端值、请求、后端条件和已知匹配/不匹配样本；清空与重置正确。
- [ ] 排序跨页稳定，使用唯一字段作次序兜底；统计范围与筛选/权限一致。
- [ ] 详情、列表、导出对枚举、时区、金额和空值的处理一致。

## 权限与业务规则

- [ ] 从已确认职责建立角色×能力×数据范围矩阵；新角色/职责变更需有需求依据。
- [ ] 未登录、权限不足、A 访问 B 数据、改受控字段等负向场景得到拒绝且无副作用。
- [ ] 列表、详情、修改、删除、批处理、导出、附件、异步任务使用同一授权边界。
- [ ] 状态流转前置条件、事务、重复请求/并发保护、服务器重算与审计符合实际需求。
- [ ] 会话持久性遵循既有安全设计；不能为“重启不掉线”取消过期或撤销策略。

## 数据、素材、界面与性能

- [ ] 核对演示数据合法性；只在授权的隔离空间补齐，保留真实数据，不重置真实账号；重新生成的本地演示账号登录口令统一123456并实际登录。
- [ ] 图片来源与引用可靠，缺失/失败态正确；完整加固必须改造登录页与不合理布局，合法素材不足时用代码/SVG实现。
- [ ] 量表格、弹窗与关键控件的实际尺寸；检查窄屏、键盘、焦点、对比度和错误提示。
- [ ] 横向滚动按产品场景判定；业务表格的内部滚动不直接列为缺陷。
- [ ] 查询分页、关联批量获取与资源加载符合真实数据量；桌面耗时任务不阻塞 UI。

## 工程与交付

- [ ] 初始 SQL 的结构、CRUD、视图、存储过程、触发器均完成业务复核和设计结论，按 [SQL 重设计](sql-redesign.md) 交付；不只做语法美化。
- [ ] 数据库方言/版本及 Studio 接收能力区分；唯一完整安装.sql包含结构、演示数据和必要对象；已有库迁移、恢复、参数模板与独立测试在文档/测试程序中分开说明，不交付重复.sql。
- [ ] 过程/触发器与应用副作用不重复；调用参数、返回映射、权限、事务及批量/并发已迁移，图表跟随真实接入状态。

- [ ] 使用现有分层、类型和错误处理；修复输入边界，不用类型断言掩盖错误。
- [ ] SQL 参数化，排序字段白名单，上传/下载鉴权，日志脱敏，不添加认证后门。
- [ ] 相关测试、构建和运行时流程有真实结果；未跑项有原因，退出码不掩盖失败。
- [ ] 最终实现与七类图证据一致；七类图按各自原生快速填写协议交付，类图/用例/架构按全文更新规则说明旧项移除，多图各一份完整图族正文。
- [ ] 保留交付与验证证据，清理本轮独占临时产物；不自动提交、发布或删除未知资源。
