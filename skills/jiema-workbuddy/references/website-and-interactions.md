# 网站前台、页面与互动能力

这份说明随技能包安装，WorkBuddy 不需要访问捷码服务器源码。先读 MCP 的 `platform_catalog` 和 `schema_get(kind=design)`；本页给出建项与验收所需的页面、互动和 AI 规则。若实时目录或服务端校验与本页不同，以实时结果为准，并据错误修正设计。**网站主题是样式选择，不是网站开关。**只填写 `config.websiteVariant`、把全部实体设为普通页，生成结果仍会以管理端为主。

## 1. 先定交付面

| 用户真正要用的入口 | 平台判断 | 设计动作 |
| --- | --- | --- |
| 仅员工录入、审批、查询 | `WEB_ADMIN` | 业务实体可保留 `pageType=""`，核实管理端权限和业务流程。 |
| 访客浏览商品、文章、公告、作品等 | 选择目录中支持 `WEBSITE_CONTENT` 的 Web 平台；若同时要小程序，选择 `VUE_WXAPP` | 至少有一个真实内容页或公告来源；配置页面类型、字段绑定和主题，单列前台页面清单。 |
| 访客还要注册、评论、点赞、收藏 | 同上 | 除公开浏览外，设计 `PUBLIC_CLIENT` 登录角色及必要权限、评论实体与绑定；下载后验证身份与交互。 |
| 只要桌面程序 | `DESKTOP` | 即使目录列出内容主题，也不能宣称生成了可在浏览器访问的网站。 |

目录的 `websiteVariants`、`hasWebUI`、`deliveryTargets` 要一起看，但 `hasWebUI` **不能单独当作前台生成开关**：当前目录的 `VUE_WXAPP` 为 `hasWebUI=false`，实际生成器仍先执行 Vue 网站，再加微信小程序；它的交付目标是 `MINI_PROGRAM`。`VUE` 生成 Vue 网站与 Spring Boot 服务；`SPRING_BOOT` / `SPRING_BOOT3`、`SSM` / `SSM3`、`JAVA_WEB` / `JAVA_WEB3` 的网站走 JSP 家族；`BOOT` / `BOOT2` 是 Thymeleaf 家族。桌面平台的主题配置用于内容界面，且目标是 `DESKTOP`，不等于 Web 前台。平台代码和数据库仍以实时目录为准，不能用页面主题改变技术栈。

## 2. 项目结构中真正启用前台的字段

先在 `config` 里按用户选定平台填写 `platform`、`database` 和 `websiteVariant`。主题 `WebSite1` 是绿色图文、`WebSite2` 是经典门户、`WebSite3` 是暖色展示；按品牌和内容选择。主题只改变前台风格，不代替实体页面配置。

逐实体决定 `pageType`，不要把数据库表全部改成网站页面：

| `pageType` | 适合的对象 | 生成含义 |
| --- | --- | --- |
| `""` | 账号、订单、库存、评论记录、支付记录等业务数据 | 普通管理页；单凭此值不生成公开内容列表与详情。 |
| `"tw"` | 商品、作品、景点等封面驱动的内容 | 图片卡片式公开浏览。 |
| `"wl"` | 公告目录、资料、可对照的内容清单 | 逐行公开列表和详情。 |
| `"bk"` | 文章、资讯、动态等文字阅读内容 | 标题、摘要、正文为主的公开阅读。 |

每个 `tw` / `wl` / `bk` 实体都要在同一实体的 `presentation` 中显式写 `version:1`、`publicPage`、`moduleRole`、`comments`。`publicPage` 必须用**该实体的真实字段 ID**绑定 `titleFieldId` 和 `sort.fieldId`；`coverFieldId`、`summaryFieldId`、`detailFieldId`、`priceFieldId`、`time` 按需求填字段 ID 或 `null`，不能用字段名称代替 ID。标题/简介/正文/封面应为文本类型，价格为数值，时间为日期类型，排序字段必须可排序；字段类型与完整形状以 `schema_get` 为准。只有作为网站公告来源时设置 `moduleRole:"ANNOUNCEMENT"`，且必须有正文；全项目最多一个公告来源。其他页面用 `moduleRole:null`。页面类型与 `publicPage` 要成套出现，不能靠默认字段名碰运气。

**游客免登录阅读需要另配 `presentation.anonymousRead`。** `publicPage` 只管展示，不等于匿名授权。用户确认游客能看已发布/在售内容时，先查实时平台目录的前台网站能力与数据库组合，再在对应非账号内容实体填写 `{ "visibilityFieldId": "真实状态字段ID", "visibleValue": "已发布" }`；值必须是该文本字段 `selectValues` 中真实声明的一项。当前 Vue、Spring Boot/SSM 的 JSP、JavaWeb 的 JSP、Boot 的 Thymeleaf 网站链均按此合同生成。公告来源可同样配置。生成器只返回该状态的记录、记录标识及 `publicPage` 绑定字段；草稿、下架、账号信息和未绑定字段不得公开。未配置时首页可打开但没有该实体的游客数据，列表和详情仍需登录。不能通过关闭拦截器或给某登录角色追加 `ALL READ` 代替。评论、收藏、点赞及业务操作继续走登录权限。

先列前台信息架构：首页栏目、导航、公开列表、搜索/筛选、详情、用户中心、每个页面的数据来源和点击后的目标。图文内容由生成器提供基础列表/详情与主题；购物车、结算、复杂会员中心、支付、跨表业务工作台等不能只靠 `pageType` 承诺完成，应在下载后的核心功能开发清单中逐项实现。管理端继续保留内容维护入口；前台只暴露用户确实需要浏览的实体和经过权限检查的字段。

## 3. 评论、点赞、收藏

**评论不是 `commentEntity:true` 一个开关。**若需要评论，为每条评论保留独立记录实体，包含所属内容、作者、正文、时间；确有回复需求时再加可空的父评论自引用，确有审核需求时再加审核状态。内容实体的 `presentation.comments` 要明确指向评论实体，以及 `targetBinding`、`authorBinding`、`contentFieldId`、`timeFieldId`、可选 `replyBinding` 和 `moderationBinding`。目标和作者引用要落到单一记录标识，字段类型与实际外键一致。评论作者的角色必须在 `loginRole.configuredSurfaces` 中确认 `PUBLIC_CLIENT`，并在 `loginRole.surfaces` 中启用；登录账号与密码字段需满足该平台的登录资格校验。评论实体的 `CREATE` 权限只让用户提交关联内容、正文及已确认的父评论，作者由 `ACTOR_FIELD`、时间由 `CURRENT_TIME` 赋值。审核可见值与字段类型一致。详细结构及校验错误以 `schema_get` 和生成计划为准；不为了通过校验放宽权限或删除业务规则。

网站内容详情模板有按用户、内容、操作类型记录的**收藏/点赞**能力，并显示计数及撤回。它随有效网站内容页生成，结构化设计里没有独立的 `features.like` 或 `features.favorite` 开关；不要编造这些字段，也不要只存一个总数字段冒充逐用户行为。需要这两项时设计可登录的用户端角色，并在下载后验证登录、重复点击、撤回、计数、数据持久化和越权访问。若用户只想在部分内容开放互动，或需要踩、关注、分享、复杂推荐，则把模板差异列入本地开发，不宣称主题选择自动提供。

## 4. “AI”要先问清所指能力

- WorkBuddy 模型负责本次需求分析、字段/关系/权限与七类手工图与派生 E-R 图语义；这不代表生成的用户网站自动接入 WorkBuddy 模型。
- `config.features.aiSqlData` 只是捷码的 **AI 示例数据**选择，和用户网站的 AI 问答无关。本连接器由 WorkBuddy 自行设计，保持 `false`；`autoDataRows` 由演示需求决定。
- `config.features.chat` 是生成模板的**在线聊天**能力，并非 AI 客服或大模型聊天；仅在用户确实需要人与人聊天且平台目录 `features.chat=true` 时启用。桌面平台当前目录不支持它。
- 内容网站模板可能基于收藏记录做协同/标签推荐。这是现有规则与相似度计算，不能称为已接入大模型。没有用户行为时不承诺个性化效果。
- 用户明确要求 AI 客服、智能搜索、LLM 推荐、摘要或审核时，记录模型/供应商、数据范围、调用点、成本和凭据依赖；标为**下载后的业务开发**，取得必要服务凭据后完成真实运行验证。未获得凭据时交付设计和明确的未验证项，不伪称生成模板已经实现。

## 5. 两次验收门槛

**建项前**：给出“实体 → 管理页/公开页类型 → 展示字段 → 匿名状态条件 → 登录角色 → 评论/反应 → 基础模板或本地开发”的覆盖清单。用户要游客浏览却没有完整 `publicPage`、有效 `anonymousRead`，或只填了主题值时，先补设计再建项。评论绑定或 `PUBLIC_CLIENT` 角色缺失时先修正，不把 400 诊断绕过去。

**生成后**：实际检查对应平台的前台首页、列表、详情和用户中心产物。Vue 家族检查 `vue/src/views/web/`，Boot 家族检查 `src/main/resources/templates/web/`，JSP 家族按生成目录检查；小程序另查 `wxapp/pages/`。在真实运行环境逐项访问前台路由，验证匿名浏览、登录/注册、内容可见范围、评论/回复、收藏/点赞状态与计数、主题布局、移动端/键盘交互及跨用户权限。某项没有生成或运行失败，就进入有界加固循环；不能用文件存在、静态清单或管理后台截图代替前台通过。

本页是随包交付的能力说明；运行时由 `platform_catalog` 给出可用平台和功能标记，`schema_get` 给出输入形状，建项及生成接口给出最终校验和实际产物。WorkBuddy 不读取捷码服务端文件。
