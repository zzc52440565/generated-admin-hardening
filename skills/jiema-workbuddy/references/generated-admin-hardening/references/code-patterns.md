# 实现提示：使用目标项目的真实技术栈

这些是决策要点，不是可复制进任何项目的完整代码模板。先复用既有 service、repository、类型与测试，避免重复创建另一套工具。

## 筛选、排序与统计

- 为“输入控件值→请求字段→边界校验→查询条件”建立一条映射；精确枚举不应只被后端当作区间。
- 排序字段从公开键映射到固定列，方向白名单，增加唯一次序；不把用户输入直接拼 SQL。
- 相同筛选与数据授权作用于列表、总数、汇总、导出。关联筛选用既有 `exists`/join 方案，避免重复主单和跨租户泄漏。
- 带已知正反样本核对返回 ID/值，不能只比较第一页行数。

## 主从保存与金额

```text
校验 DTO 和请求主体
开启事务
  读取并锁定/校验版本的授权主单
  校验当前状态允许变更
  校验每个既有明细 ID 都属于该主单且未重复
  读取可信价格/费率，按真实计费规则计算十进制金额
  校验数量、舍入、折扣及合计
  写表头与明细 diff，按业务规则保留历史
  提交或整体回滚
返回真实保存结果
```

展示层可以预估金额，后端不得信任传来的合计。货币使用项目现有定点/十进制类型；不要复制浮点 `Number` 相乘作为结算依据。

## 回收站与会话

- 回收站只绕开逻辑删除过滤，不能绕开租户、授权和审计；优先使用 ORM 已有显式 API，原生 SQL 仍参数化并保留完整范围条件。
- 会话密钥从现有秘密管理/配置读取；持久化、撤销、过期和轮换遵循项目机制，不把硬编码密钥或永不过期当修复。
- 401 与 403 区分处理，保留合理返回地址并防止开放重定向；不能把所有业务错误一律清会话。

## 数据与资源

- 本地开发数据库（本技能新建的专用实例）和所有本轮交付的演示／测试账号，口令统一为 `conventions.localDemo.password`。用应用真实 PasswordEncoder/Hasher 编码，逐角色用 `conventions.localDemo.password` 真实登录；配置、种子 SQL、测试与账号清单同步。已有且归属明确的本轮合成账号不一致时，在已授权的隔离测试范围内纠正；不得修改真实或生产账号，不得接管来源不明的既有数据库；此时另建隔离实例或账号。不得修改认证算法、写明文哈希或增加登录后门。
- 资源删除前查 CSS、模板、代码和动态映射引用；不因“未被静态搜索发现”就删文件。
- 图片只在当前需求下补齐，沿用现有素材与生成工具；安装新图形库和下载外部素材需要相应权限。

## SQL 重设计

初始 SQL 优化不是仅给现有表加索引。完整流程见 [sql-redesign.md](sql-redesign.md)，CRUD/视图/过程/触发器契约见 [sql-object-design.md](sql-object-design.md)。本文中的服务事务示意不要求该事务必须放在应用层；若真实设计迁入存储过程，迁移调用并移除重复写入。需要的 schema 变更按当前用户授权和真实迁移方式交付，不能沿用旧版“一律不增删字段”的限制。
