# SQL 重设计验收矩阵

必读 [数据库重设计与证据合同](database-contract.md)，它定义数据全量重建、对象清单、真实回读与验收失效规则。

先完成 SQL、调用方迁移、测试编写和静态审查，再集中验收。已有项目优先使用其数据库测试/迁移 runner；执行前确认数据库归属和授权，不因技能包含测试就连接生产。

## 执行层次

1. **静态一致性**：方言/版本/执行工具明确；所有对象、列、键、参数和调用方可追溯；原→新映射及对象依赖完整；无凭据、失效 DEFINER、数据库名硬编码和无依据扩展。
2. **真实引擎部署**：在已授权隔离空库按 manifest 安装，核对系统目录中对象、签名、视图列和触发绑定；仅 AST 解析通过不代表可执行。
3. **行为与集成**：绑定真实驱动参数，执行正反例，核对返回、影响行数和最终数据；覆盖 ORM/Mapper/服务实际调用，不只在客户端手工运行。
4. **升级与恢复**：有现存库时从具有代表性的旧结构/数据执行版本迁移，核对记录、关联、金额、账号与权限；验证已声明的恢复路线，不假定回滚会恢复已删除数据。

不能用 SQLite 代替 MySQL/SQL Server 的过程、触发器、锁和事务验收；也不能用同方言语法解析器代替真实服务器。缺工具/版本/凭据时记录未验证项，继续能做的静态工作，不伪造成功。

## 最小行为覆盖

| 类别 | 正向 | 负向/边界 | 必须核对 |
| --- | --- | --- | --- |
| 结构 | 合法数据与关联可写 | 重复业务键、空值、越界、非法外键、既有脏数据 | 约束真正生效、历史兼容、错误可定位 |
| 新增 | 主从一起保存、返回真实ID | 部分明细失败、伪造归属、重试/重复 | 原子性、幂等需求、受控字段不被篡改 |
| 查询 | 已知匹配/不匹配、分页/排序/统计 | 空结果、NULL、重复join、越权、时区边界 | ID/列/总数/汇总准确，敏感字段不泄漏 |
| 修改 | 合法状态与版本更新 | 过期版本、越权字段、无匹配、批量超范围 | 影响行数及冲突语义、没有部分提交 |
| 删除/作废 | 允许状态、指定范围 | 空集合、关联限制、已锁定历史、跨用户 | 非目标数据不变、恢复/保留规则符合需求 |
| 视图 | 与独立业务查询对照 | 1对多重复、缺关联、软删、敏感列 | 粒度、聚合、授权范围及调用方映射 |
| 存储过程 | 合法参数调用、返回集/码 | 非法参数、中途故障、并发、无权限 | 原子性、错误传播、事务归属和调用契约 |
| 触发器 | 目标事件触发一次 | 未改目标值、多行批量、递归、异常、回滚 | 副作用准确、无重复计算、不会阻塞无关业务 |
| 迁移 | 从代表性旧版升级 | 已应用版本、阶段失败、旧对象依赖 | 可重试/停止语义，数据无意外丢失 |

涉及并发库存/余额/编号等真实共享资源时，使用独立连接构造竞争，验证不变量与重试，不能只顺序调用两次当并发。查询优化使用代表性隔离数据及执行计划；执行计划带实际执行的命令不能用于未授权写操作。

## 测试数据与清理

只使用本轮独占标识/数据库/schema 的样本；记录初始值和创建范围。业务断言只针对目标对象，不能测试后按表清空。数据库事务/DDL 回滚能力依版本核对；不能回滚时使用已获授权的隔离环境与恢复策略。运行中的数据库/container/volume 归属不清时不停止或删除。

输出逐项 `passed / failed / unverified / not-applicable`，附具体理由和真实命令、数据库版本、输入/预期/实测。完成标准是已承诺类别均有设计结论、相关对象定义与调用迁移一致、必要验证有结果及明确限制；不把“生成了 SQL”写成“数据库已优化上线”。
