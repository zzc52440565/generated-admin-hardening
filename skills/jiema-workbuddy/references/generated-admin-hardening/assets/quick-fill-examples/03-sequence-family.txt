# 时序图图族 v1
## 时序：root | 订单受理教学系统总览
参与者：访问者 actor
参与者：浏览器页面 boundary
参与者：HTTP入口 control
参与者：业务服务 control
参与者：数据访问层 entity
参与者：MySQL database
消息：访问者 -> 浏览器页面：登录或办理订单 sync
消息：浏览器页面 -> HTTP入口：请求凭据或携带会话的业务请求 sync
消息：HTTP入口 -> 业务服务：已验证身份与业务参数 sync
消息：业务服务 -> 数据访问层：查询或事务命令 sync
消息：数据访问层 -> MySQL：参数化SQL sync
消息：MySQL -> 数据访问层：记录或约束异常 return
消息：数据访问层 -> 业务服务：持久化结果 return
消息：业务服务 -> HTTP入口：业务结果或拒绝原因 return
消息：HTTP入口 -> 浏览器页面：授权范围内的数据或错误 return
消息：浏览器页面 -> 访问者：展示结果 return
## 时序：login | 账号登录
参与者：访客 actor
参与者：登录页面 boundary
参与者：认证服务 control
参与者：账号仓储 entity
参与者：会话服务 control
消息：访客 -> 登录页面：账号与密码 sync
消息：登录页面 -> 认证服务：提交登录资料 sync
消息：认证服务 -> 账号仓储：按唯一账号读取密码哈希和角色 sync
消息：账号仓储 -> 认证服务：账号记录或空值 return
片段开始：alt 账号存在且应用编码器核验通过
消息：认证服务 -> 会话服务：创建绑定账号与角色的会话 sync
消息：会话服务 -> 认证服务：会话令牌 return
消息：认证服务 -> 登录页面：会话令牌和本人资料 return
片段否则：账号不存在或密码错误
消息：认证服务 -> 登录页面：统一的认证失败信息 return
片段结束
消息：登录页面 -> 访客：显示登录结果 return
## 时序：submit | 提交订单
参与者：客户 actor
参与者：订单入口 boundary
参与者：订单服务 control
参与者：订单仓储 entity
参与者：MySQL database
消息：客户 -> 订单入口：会话与请求号及商品数量 sync
片段开始：alt 已登录客户且字段数量有效
消息：订单入口 -> 订单服务：可信客户身份与合法参数 sync
消息：订单服务 -> 订单仓储：按客户和请求号查询 sync
消息：订单仓储 -> 订单服务：已有订单或空值 return
片段开始：alt 已有相同请求号且内容一致
消息：订单服务 -> 订单入口：返回原订单编号 return
片段否则：尚无该请求
片段开始：critical 订单与明细单事务
消息：订单服务 -> MySQL：开启事务并插入订单和明细 sync
片段开始：alt 全部写入成功
消息：订单服务 -> MySQL：提交事务 sync
消息：订单服务 -> 订单入口：返回新订单编号 return
片段否则：唯一键竞争或其他写入异常
消息：订单服务 -> MySQL：回滚事务 sync
消息：订单服务 -> 订单仓储：唯一键冲突时读取原请求并比较内容 sync
消息：订单仓储 -> 订单服务：原订单或不一致或存储错误 return
消息：订单服务 -> 订单入口：返回原编号或冲突与失败信息 return
片段结束
片段结束
片段否则：请求号已存在但内容不同
消息：订单服务 -> 订单入口：拒绝请求号复用 return
片段结束
片段否则：未登录或角色无权或参数无效
消息：订单入口 -> 客户：返回认证授权或字段错误 return
片段结束
消息：订单入口 -> 客户：返回本次办理结果 return
## 时序：mine | 查询本人订单
参与者：客户 actor
参与者：查询入口 boundary
参与者：订单服务 control
参与者：订单仓储 entity
消息：客户 -> 查询入口：会话与分页筛选条件 sync
片段开始：alt 客户身份及分页参数有效
消息：查询入口 -> 订单服务：会话中的客户ID与条件 sync
消息：订单服务 -> 订单仓储：强制customerId过滤并稳定排序分页 sync
消息：订单仓储 -> 订单服务：本人记录与总数或空集 return
消息：订单服务 -> 查询入口：本人分页结果 return
消息：查询入口 -> 客户：列表或空态 return
片段否则：无权或分页参数无效
消息：查询入口 -> 客户：认证授权或校验错误 return
片段结束
## 时序：admin-query | 管理员查询订单
参与者：管理员 actor
参与者：管理入口 boundary
参与者：订单服务 control
参与者：订单仓储 entity
消息：管理员 -> 管理入口：会话与状态分页条件 sync
片段开始：alt 管理员身份且条件有效
消息：管理入口 -> 订单服务：管理员查询条件 sync
消息：订单服务 -> 订单仓储：按状态过滤并稳定排序分页 sync
消息：订单仓储 -> 订单服务：匹配记录与总数或空集 return
消息：订单服务 -> 管理入口：分页结果 return
消息：管理入口 -> 管理员：列表或空态 return
片段否则：非管理员或条件无效
消息：管理入口 -> 管理员：拒绝或校验错误 return
片段结束
